The whole world of Wednesday 25 November 2026 on one front page: tankers burning in the Strait of Hormuz, Riyadh's tallest tower hit again, Hamas's security chief killed in Gaza, Odesa struck as Russia's leaked war dead pass 490,334 — plus COP31's failed climate talks and Huawei's U.S. conviction in the ticker.

The four photographs were generated from the day's reporting; the page itself is composed by `compose.py` so every headline is crisp and spelled exactly. `main.py` ships the finished page byte for byte.

## Run it

```sh
python3 main.py
```

Writes the image to `/output/entry.png` (1024×1024) — the same bytes on every run.
